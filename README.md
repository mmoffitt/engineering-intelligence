# High School Internship Proposal

### 1) Internship Title
**Engineering Intelligence**

### 2) Host Organization
[The Neurosynthetic Research Institute](https://neurosynthetic.org/)

### 3) Overview
This internship gives a high school student hands-on experience in programming and AI research over one academic year, with a focus on ARC-AGI. ARC-AGI is a strong learning environment because many starter tasks are concrete and approachable (for example, transposing a grid or changing colors). At the same time, these tasks build core skills in problem-solving, coding, and experimentation. The project also introduces the student to an important topic in the AI community that can support long-term academic and career growth.

### 4) Prerequisites
No prior programming experience is required for this internship. Basic experience with syntax-heavy file editing (like HTML/CSS) is helpful, but not required. We will start from programming fundamentals and build up step-by-step through guided exercises, examples, and mentorship.

### 5) Background
ARC-AGI (Abstraction and Reasoning Corpus for Artificial General Intelligence) is a benchmark designed to test how well systems can learn and apply abstract rules from small examples. Each task presents an input grid and an expected output grid, and the goal is to infer the rule that transforms one into the other.

For example, the goal of task [08ed6ac7](https://arcprize.org/tasks/08ed6ac7) is to apply colors to lines based on their relative length:

Many beginner-friendly tasks involve clear operations like rotating or transposing grids, identifying simple patterns, or remapping colors. This makes ARC-AGI a good environment for learning while still connecting to important open questions in modern AI research.

### 6) Internship Scope
The internship will focus on the following deliverables:
- Building small Python programs, each capable of solving a particular ARC task
- Developing a small utility that generates HTML to help visualize ARC problems
- Working with AI agents to automate the discovery of programs
- Developing a reusable library that encapsulates useful ARC concepts
- Writing a report outlining key findings and areas of future work

### 7) Duration & Time Commitment
- **Program length:** 8 months (September 2026 - April 2027)
- **Weekly commitment:** 2-3 hours/week during school year
- **Schedule:** Flexible and mostly self-paced, with one in-person meeting per week on AHS campus to review questions and core concepts
- **Location:** Hybrid (primarily remote + weekly in-person check-in)

### 8) Learning Goals
By the end of the internship, the student should be able to:
- Write and debug basic-to-intermediate code independently
- Use version control (`git`) and collaborate on project workflows
- Conduct small research tasks, summarize findings, and present results
- Build at least 1-2 complete portfolio projects
- Communicate progress clearly in written updates and short demos

### 9) Program Structure by Phase
**Phase 1: Onboarding & Foundations (Months 1-2)**
- Tool setup, coding standards, communication expectations
- Intro mini-projects and guided exercises
- Weekly mentorship check-ins

**Phase 2: Skill Building & Contributions (Months 3-6)**
- Contribute to real tasks with close supervision
- Practice issue tracking, documentation, and code reviews
- Deliver first portfolio-quality project

**Phase 3: Ownership Project (Months 7-8)**
- Define and execute a capstone project with milestones
- Present progress at regular intervals
- Final demo + reflection on lessons learned
